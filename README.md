# Solidity Labs

Repositorio con implementaciones y ejemplos prácticos de funcionamiento de Smart Contracts sobre Ethereum utilizando Solidity y Foundry.

## Contenido actual

El repositorio incluye un primer contrato `SimpleVault.sol` que implementa:

* depósitos de ETH;
* retiradas de ETH;
* balances individuales por usuario;
* eventos `Deposit` y `Withdrawal`;
* validaciones de saldo;
* interacción con múltiples usuarios;
* tests automatizados con Foundry;
* validación de operaciones esperadas y reverts.

## Stack

* Solidity
* Foundry
* Forge

## Ejecutar los tests

```bash
forge test
```

# English

Repository containing practical Smart Contract implementations and Ethereum development examples using Solidity and Foundry.

## Current content

The repository currently includes a `SimpleVault.sol` contract implementing:

* ETH deposits;
* ETH withdrawals;
* per-user balances;
* `Deposit` and `Withdrawal` events;
* balance validations;
* multiple-user interactions;
* automated Foundry tests;
* expected-operation and revert validation.

## Stack

* Solidity
* Foundry
* Forge

## Run tests

```bash
forge test
```
